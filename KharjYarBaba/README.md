# خرج‌یار بابا

اپ اندروید: پیامک‌های بانکی را خودکار می‌خواند، بلافاصله با اعلان می‌پرسد «این چی بود؟» (۳ دکمه‌ی یک‌لمسی)، و خرج ماه شمسی را نشان می‌دهد.

## اجرا
1. پوشه را در Android Studio (Koala یا جدیدتر) باز کنید و Sync کنید.
2. روی گوشی واقعی اندروید 8 به بالا اجرا کنید (پیامک روی شبیه‌ساز راحت تست نمی‌شود).
3. اجازه‌ی پیامک و اعلان را بدهید؛ پیامک‌های ۹۰ روز اخیر هم وارد می‌شود.

## نکات
- فقط اندروید؛ iOS اجازه‌ی خواندن خودکار پیامک نمی‌دهد.
- اطلاعات فقط در پایگاه داده‌ی محلی (Room) می‌ماند و بک‌آپ ابری غیرفعال است.
- گوگل‌پلی دسترسی پیامک را محدود می‌کند؛ برای استفاده‌ی خانوادگی APK را مستقیم نصب کنید.
- الگوهای تحلیل پیامک در Parser.kt است؛ اگر بانک بابا فرمت متفاوتی دارد، چند نمونه پیامک بدهید تا تنظیم شود.
